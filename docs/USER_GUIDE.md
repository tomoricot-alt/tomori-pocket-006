# TOMORI POCKET の使い方 👛

おこづかいやお年玉、使ったお金をかんたんに記録して、「いくら残ってるかな？」がすぐ分かるアプリです。

## はじめに

1. **ホーム**の「はじめの残高」で、いま持っているお金を入れよう（あとから変えられるよ）。
2. 入れなくても大丈夫。そのときは 0円 からスタートするよ。

## お金を記録しよう

1. 下の「✏️ 記録」をタップ。
2. **収入**（もらった）か**支出**（使った）を選ぶ。
3. カテゴリを選ぶ。
   - 収入：おこづかい／お年玉／その他の収入
   - 支出：飲食／文房具／趣味・ゲーム／交通費／その他
4. **金額**を入れる（数字だけ。例：500）。
5. **日付**を確認（今日が入っているよ。「前の日」「次の日」で変えられる）。
6. 「記録する」をタップ！

> 金額が 0円・マイナス・小数・文字のときは登録できないよ。

## 見てみよう

- 🏠 **ホーム**：いまの残高と、今月の収入・支出。
- 📒 **履歴**：月ごとの記録の一覧。◀ ▶ で月を変えられるよ。
- 📊 **集計**：何にいくら使ったか（カテゴリ別）と、月ごとの収支。

## まちがえたとき

履歴の記録をタップすると、**直す**ことも**削除**もできるよ。

## 大事なお知らせ ⚠️

- 記録は**このスマホ・パソコンのブラウザの中だけ**に保存されます。ほかの人や外のサーバーには送られません。
- ブラウザの「サイトデータ」や「履歴」を削除すると、**記録が消えることがあります**。
- 別のブラウザや別の端末では、記録は引き継がれません。
- 名前・学校名・銀行口座・カード番号などは、入れなくてOK（入れる場所もないよ）。
- 使うときは、無理のない範囲で、おうちの人とも相談しながら使ってね。
