# 開発レポート：TOMORI POCKET (APP 006)

## 実装内容

- Expo SDK 57 / React Native 0.86 / React Native Web / TypeScript（strict）。外部ランタイム依存は `@react-native-async-storage/async-storage`（Webでは localStorage）のみ。
- 画面：ホーム、記録（新規・編集・削除）、履歴（月別・種別絞り込み）、集計（カテゴリ別棒グラフ、月別収支・月末残高）。ナビゲーションライブラリは使わず簡易タブ。
- グラフは外部ライブラリなしの View ベース棒グラフ。
- `src/logic/`：money（金額検証・円表示）、date（日付検証・月操作）、calc（残高・集計）、ops（追加・更新・削除）、validate（保存データ検証・ID生成）。UIから分離した純粋関数。
- 保存：変更のたびに自動保存、起動時に読込＋検証。保存失敗時は画面に警告。
- 削除確認は `Alert` が Web で動かないため画面内の確認UIにした。
- GitHub Actions：PR で型チェック・テスト・ビルド、main への push で Pages 公開。

## テスト結果

| 項目 | 結果 |
|---|---|
| `npm run typecheck` | エラーなし |
| `npm test`（4ファイル・39件） | 全件成功 |
| `npm run build:web` | 成功 |
| ブラウザ操作確認（Chromium・390px / 1280px） | 不正金額の拒否、収入・支出の登録・編集・削除、残高反映、再読み込み後のデータ保持、コンソールエラーなしを確認 |

ユニットテスト対象：収入/支出の登録・編集・削除、残高、月別集計、カテゴリ別集計（合計の整合性）、日付処理（うるう年・月またぎ・年またぎ）、不正金額、JSON往復と壊れたデータの除去。

## 残課題・注意

- 実機 iPhone での確認は未実施（Chromium のモバイルサイズ表示で代替）。公開後に Safari で確認してほしい。
- 日付入力はテキスト＋前後日ボタン（ネイティブのカレンダーピッカーなし）。
- データの書き出し／取り込み（バックアップ）機能はなし。ブラウザデータ削除で消えるため、将来の改善候補。
- 予算設定・目標貯金などは今回の範囲外。
- Pages 公開には、リポジトリ設定で Source を「GitHub Actions」にする操作が必要。
- `npm audit` は Expo 依存の開発ツール由来の警告を含む（本番バンドルには影響しない想定）。
